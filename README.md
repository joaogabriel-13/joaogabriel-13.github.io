## 🧪 Testing (E2E com Playwright)

Este projeto inclui testes end-to-end usando Playwright para garantir que os produtos (calculadoras e prescrições) sejam exibidos corretamente.

```bash
# Instalar dependências
npm install

# Executar testes
npm test
```
